# 01 · 需求拆解

## 目标

开发一个用于快速部署本地项目到服务器上的 **Windows 桌面应用**。当前分支主线为 Tauri v2 + Rust + React，核心目标是识别本地项目中的变更并同步到远程服务器。

## 主要功能

- **服务器管理**：维护多台目标服务器及其凭据信息
- **项目管理**：维护多个本地项目，绑定默认服务器与远端部署路径
- **协议支持**：使用 SFTP（推荐）/FTP 上传项目文件
- **基于 Git 的版本选择**：通过本地 Git 仓库状态选择本次部署的提交，识别两个提交之间的变更文件

## 功能拆解

| 模块 | 核心能力 |
|---|---|
| 服务器管理 | 增删改查 SSH/FTP 凭据、连接测试、密钥安全保存 |
| 项目管理 | 绑定本地路径 + 远程部署路径 + 关联默认服务器 + 排除规则 |
| Git 变更识别 | 列出提交、对比两次提交差异、识别新增/修改/删除/重命名 |
| 文件同步 | SFTP/FTP 增量上传、保持目录结构、删除远端已删文件 |
| 部署历史 | 记录每次部署的 commit、文件清单、状态，可回滚到上一版本 |

## 非功能需求

- **运行平台**：当前开发分支仅聚焦 Windows x64 桌面应用；其他平台不属于本分支交付范围
- **离线可用**：不依赖云服务，所有数据本地化
- **安全**：凭据加密存储；明文密码/私钥**不得**落库
- **可观测**：每次部署有完整日志与文件级状态
- **易扩展**：协议适配器、Hook 钩子可后续插入
